মেধার লড়াই (Battle of Brains) — Android Source Project v4

এই প্রজেক্টটি Android অ্যাপের সোর্স কোড; এটি APK নয়। Android WebView-এর ভেতরে অফলাইন HTML কুইজ চলে।

বর্তমান বৈশিষ্ট্য
- বাংলা ও English ভাষা বদল
- প্রতি রাউন্ডে ১০টি প্রশ্ন
- সঠিক উত্তরে +১ পয়েন্ট
- ভুল উত্তরে −০.২৫ পয়েন্ট
- ১০টি প্রশ্ন শেষ হলে পরের লেভেল আনলক
- পয়েন্ট, লেভেল ও প্রশ্ন ডিভাইসের লোকাল স্টোরেজে সংরক্ষণ
- অ্যাডমিন প্যানেল থেকে প্রশ্ন যোগ, সম্পাদনা ও মুছে ফেলা
- JSON প্রশ্ন ব্যাকআপ ডাউনলোড ও পুনরুদ্ধার
- ১০টি প্রাথমিক প্রশ্ন

গুরুত্বপূর্ণ সীমাবদ্ধতা
- এটি অফলাইন প্রোটোটাইপ; কোনো সার্ভার, ইউজার অ্যাকাউন্ট বা কেন্দ্রীয় ডেটাবেস নেই।
- একাধিক ব্যবহারকারীর মধ্যে পয়েন্ট/লিডারবোর্ড শেয়ার হয় না।
- বিজ্ঞাপন বা পেইড ফিচার এখনো যুক্ত হয়নি।
- বর্তমান ১০টি প্রশ্ন দিয়ে প্রথম লেভেল পরীক্ষা করা যাবে। পরের লেভেলগুলো বাস্তবে চালাতে অ্যাডমিন প্যানেল থেকে আরও প্রশ্ন যোগ করতে হবে।
- প্রশ্নের কঠিনতা এখনো স্বয়ংক্রিয়ভাবে লেভেলভিত্তিক সাজানো হয়নি; এটি পরবর্তী উন্নয়নের কাজ।

APK তৈরির জন্য
১. Android Studio-তে এই ফোল্ডারটি খুলুন।
২. Android SDK Platform 35 এবং Gradle plugin 8.7.3 ডাউনলোড/সেটআপ সম্পন্ন হতে দিন।
৩. Gradle Sync সফল হলে Build > Build Bundle(s) / APK(s) > Build APK(s) নির্বাচন করুন।
৪. সফল হলে app/build/outputs/apk/debug/app-debug.apk পাওয়া যাবে।

এই পরিবেশে Android SDK, Gradle এবং Android build tools অনুপস্থিত; তাই এখানে APK কম্পাইল করা যায়নি।
